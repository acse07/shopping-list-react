# Список покупок

Учебное приложение на React и Vite без бэкенда.

Можно добавить товар с названием и ценой, удалить его и увидеть общую стоимость покупок. Валюта — тенге. После перезагрузки страницы список очищается.

## Запуск

```sh
npm install
npm run dev
```

Сборка: `npm run build`. Просмотр сборки: `npm run preview`.

## State и props

- `src/App.jsx` — компонент со списком товаров и полями формы в `useState`. Добавляет и удаляет товары, вычисляет общую сумму.
- `src/components/ShoppingItem.jsx` — отдельный компонент товара. Получает товар через prop `item` и обработчик удаления через prop `onDelete`.
- `src/styles.css` — небольшое оформление с адаптацией для телефона.

Цены хранятся в целых тиынах. Можно вводить дробную цену через точку или запятую; отрицательные цены и больше двух знаков после запятой не допускаются.

## Публикация

Workflow `.github/workflows/deploy.yml` собирает приложение и публикует его в GitHub Pages при каждом push в `main`. В настройках репозитория Pages → Source должно быть выбрано **GitHub Actions**. Путь к ресурсам задаётся при сборке по имени репозитория.
